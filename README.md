# نظام فواتير وميديا OMS (OMS Business Suite)

> نظام ويب داخلي متكامل لإدارة وتنظيم فواتير وحملات ميديا شركة **OMS** المتخصصة في التسويق والتصميم والبرمجيات بالجنيه المصري (EGP).

**التطوير والتنفيذ**: MDE – Matrix Data Egypt  
**الهوية المعتمدة**: الأحمر الأساسي (`#DC2626`)، الأسود الداكن (`#171717`)، والأبيض (`#FFFFFF`).

---

## 📁 أقسام وبوابات النظام (System Portals & Separation)

تم تصميم النظام بفصل تام بين بوابات ومواقع العمل، مع ربط مركزي لقاعدة البيانات:

### 1. 🛡️ بوابة الإدارة المركزية (OMS Admin Hub) - مجلد `admin/`
- **الخادم (Backend)**: المنفذ `5003` (`admin/backend`)
- **الواجهة (Frontend)**: المنفذ `5175` (`admin/frontend`) -> رابط: `http://localhost:5175`
- **المسؤولية**:
  - تسجيل وإدارة المستخدمين وتحديد اختصاص كل موظف:
    * 🔴 **قسم الفواتير والمحاسبة فقط (`INVOICE`)**: ممنوع تلقائياً من دخول قسم الميديا.
    * 🔵 **قسم الميديا فقط (`MEDIA`)**: ممنوع تلقائياً من دخول قسم الفواتير.
    * 🟢 **كافة الأنظمة (`ALL` / Admin)**: صلاحية كاملة.
  - تفعيل وتعطيل الحسابات بنقرة واحدة، وإعادة تعيين كلمات المرور، وروابط انتقال سريعة.

### 2. 📺 قسم الميديا والإعلانات (OMS Media) - مجلد `media/`
- **الخادم (Backend)**: المنفذ `5002` (`media/backend`)
- **الواجهة (Frontend)**: المنفذ `5174` (`media/frontend`) -> رابط: `http://localhost:5174`
- **المسؤولية**:
  - تسجيل الدخول المخصص باسم المستخدم (`Username`) وكلمة المرور (`Password`).
  - التحقق من صلاحيات الموظف (يمنع حسابات الفواتير من الدخول).
  - إدارة العملاء (مربوطين مع المحاسبة والسجل الضريبي)، الموردين، القنوات، أنواع المحتوى، والحملات.
  - فلاتر وبحث متقدم بنمط **Kaggle**، واستيراد وتصدير إكسل/CSV بالأعمدة التسعة المعتمدة.
  - زر بضغطة واحدة لإصدار فاتورة رسمية داخل قسم المحاسبة.

### 3. 📄 نظام المحاسبة والفواتير (OMS Invoice) - مجلدات `server/` و `client/`
- **الخادم (Backend)**: المنفذ `5001` (`server/`)
- **الواجهة (Frontend)**: المنفذ `5173` (`client/`) -> رابط: `http://localhost:5173`
- **المسؤولية**:
  - تسجيل الدخول باسم المستخدم أو البريد (يمنع موظفي الميديا من الدخول).
  - دورة حياة الفاتورة، نظام الاعتماد المالي متعدد المستويات، الضرائب (14% VAT و 1% WHT)، سجلات التدقيق المالي.
